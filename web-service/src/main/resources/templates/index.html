Java-приложение развернуто через Docker

Статус развертывания: ✅ Готово к работе

Приложение запущено в изолированной среде с помощью Docker. Контейнеризация обеспечивает воспроизводимость окружения и упрощает доставку в production.

Краткая схема запуска

# Сборка образа
docker build -t java-app .

# Запуск контейнера
docker run -p 8080:8080 java-app

Пример Dockerfile для Java-приложения

FROM eclipse-temurin:17-jre-alpine
WORKDIR /app
COPY target/my-app.jar app.jar
EXPOSE 8080
ENTRYPOINT ["java", "-jar", "app.jar"]
